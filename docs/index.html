Simon & Gaythan · phone app · Add to Home Screen

WhatsApp does not allow apps to pull chats automatically. Export the chat (without media) and import it here to refresh.

Import official WhatsApp export

Drop a .txt or .zip here, or pick a file. Use Without media.

Android — export then import
  1. Open the 1:1 chat with Gaythan.
  2. Three dots → More → Export chat.
  3. Choose Without media.
  4. Save the .txt or .zip to Files / Drive.
  5. Return here → Choose export file (or share the file into this app if the picker shows it).
iPhone — export then Open in this app
  1. Open the chat → tap the contact name at the top.
  2. Export Chat → Without Media.
  3. Save to Files (On My iPhone or iCloud Drive).
  4. In this app, tap Choose export file → Browse → Files → pick the export.
  5. If you use Share from Files, pick this Home Screen app if it appears under Open in…

What this app cannot do

  • It cannot log into WhatsApp, scrape WhatsApp Web, or download the thread by itself. That would violate WhatsApp’s terms.
  • After the first load, the dashboard works offline; updating still needs a new export file.
  • Last import + results stay on this phone (IndexedDB / localStorage).

Add to Home Screen (this is the “install”)

GitHub cannot put a binary on the App Store. Open this HTTPS site in the phone browser, then:

iPhone (Safari)

  1. Open the GitHub Pages link in Safari (not in-app Instagram/Chrome wrappers if Add to Home Screen is missing).
  2. Share → Add to Home Screen → Add.

Android (Chrome)

  1. Open the same link in Chrome.
  2. Menu → Install app or Add to Home Screen.
