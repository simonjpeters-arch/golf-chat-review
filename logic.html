2. Scope — what counts as golf

Included

  • Pitch / range — Urban Golf, Pitch Golf, bay bookings, membership sessions
  • Real / 18-hole — Trent Park, courses outside London, MK trips, tee times
  • Planned together — invites, bookings, “golf later / tomorrow / this weekend”
  • Skip outcomes — bail, cancel, no-show, or one played solo because the other didn’t come

Excluded

3. Search approach

Systematic grep over the full export, then manual context reading around each hit (typically ±20–50 lines).

Primary patterns

  • golf — all mentions reviewed or filtered by pattern
  • Golf + time: this weekend, Saturday, Sunday, tomorrow, tonight, Friday
  • Golf + failure: skip, bail, cancel, pull out, not turn, no show

Apology / bail phrasing (in golf context)

sorry not coming · sorry can't make · not coming · can't make it · won't make it · can't do tonight · pull out · bailing · not turning up · decided against · don't fancy · not going to be able · haven't gone golf · you go by all means · shall I cancel · go ahead and cancel

Weekday → weekend pass

Additional search for Mon–Thu messages referencing upcoming Fri–Sun golf, then trace forward to the weekend for outcome.

4. Inclusion criteria

Confirmed no-show

All must apply:

  1. Planned or booked golf together (or clear same-day invite)
  2. One party did not attend, or both agreed to cancel
  3. Identifiable date (message or referenced play date)
  4. Clear attribution — Simon, Gaythan, or Both

Borderline / unclear

  • Ambiguous golf context (e.g. “Not coming boo” on a cycle ride)
  • Double-booking awareness, not a skip with Simon
  • Membership frustration, not one session
  • Aggregate accusations (“54th booking”) without one dated round
  • Wrong activity (swim, drug delivery, virtual PGA, running race)
  • Forgot to book — organisation failure, not a skip

False positive (documented separately)

Looked like a skip but they played — e.g. reluctance then moved to 5pm/6pm; banter “you bailing” then went anyway.

5. Weekday → weekend failure logic

StepRule
1Find golf on Mon–Thu referencing upcoming Fri–Sun
2Record who planned and mid-week quote
3Read Fri–Sun (and Mon after if away) for outcome
4Confirmed — explicit skip/cancel on planned weekend
5Fizzled — agreed mid-week but no round; never booked; silent drop
6Who failed — bailer, both, or Unclear

Confirmed example: Thu 10/27/22 plan for Sat Trent → Sat both skipped.

Fizzled example: Mon 2/27/23 “golf maybe this weekend” → never booked.

8. Limitations

  • Export gaps — deleted messages or other channels not visible
  • Ambiguous tone — banter requires context; borderline rows intentional
  • Date inference — message date used when play date not explicit
  • Solo play — counts as skip for absent party, not joint success
  • Manual classification — not fully automated; rules above guide judgment
  • Private chat — verbatim quotes; share summaries responsibly
